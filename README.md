# ResumeMatch AI — MVP

เว็บแอปช่วย HR เปรียบเทียบเรซูเม่ PDF/รูปภาพกับเกณฑ์ตำแหน่งงานด้วย React + TypeScript + Vite และ Node.js + SQLite

## สิ่งที่มีใน MVP
- Dashboard สรุปจำนวนผู้สมัครจากข้อมูลในระบบจริง (ข้อมูลตัวอย่างติดป้ายกำกับชัดเจน)
- เพิ่ม/แก้ไข/ลบตำแหน่งงานและเกณฑ์ พร้อมตรวจสอบน้ำหนักรวม 100%
- อัปโหลด PDF และรูปภาพหลายไฟล์ อ่าน PDF ด้วย PDF.js และใช้ Tesseract OCR ในเครื่องกับ PDF สแกน/รูปภาพ พร้อมรายงานข้อผิดพลาดรายไฟล์
- จัดเก็บไฟล์ต้นฉบับจริงแยกจากข้อความที่อ่านได้ใน `data/uploads` และ SQLite พร้อมปุ่มดูเอกสาร/ดาวน์โหลดในรายการ รายละเอียด และหน้าจอเปรียบเทียบ
- ตัวอย่าง PDF เปิดในตัวอ่านเอกสารของเบราว์เซอร์ (รองรับหลายหน้าและซูมตามเบราว์เซอร์); รูปภาพสามารถขยาย/ย่อได้
- วิเคราะห์คะแนนจากการครอบคลุมคำสำคัญที่ HR กำหนด คะแนนเป็นค่าแบบคำนวณได้ ไม่ใช่คะแนนสุ่ม
- ตารางค้นหาและกรองตามตำแหน่ง คะแนน ทักษะ การศึกษา ประสบการณ์ และสถานะ พร้อมเรียงตามคะแนน/วันที่/ประสบการณ์ ใช้ Pagination เปรียบเทียบผู้สมัคร และส่งออก CSV
- สถานะคัดเลือกเพิ่มเติม บันทึกการเปลี่ยนสถานะ เหตุผลที่ไม่ผ่าน และโน้ตภายในทีม HR
- รายละเอียดผู้สมัคร แก้ไขข้อมูลที่ดึงมา บันทึกสถานะ HR ใน localStorage
- รายงาน CSV และสรุปข้อมูลที่อ่านไม่สำเร็จ/ต้องตรวจสอบ
- AI Insights เป็นตัวเลือกผ่าน backend; คะแนนยังมาจากเกณฑ์ที่กำหนด ไม่ได้มาจาก AI

## วิธีติดตั้งและรัน
ต้องติดตั้ง Node.js รุ่น 20 ขึ้นไป (แนะนำรุ่น LTS) ก่อน

```bash
npm install
```

เปิด Terminal แรกแล้วรัน backend:

```bash
npm run server
```

เปิด Terminal ที่สองแล้วรันหน้าเว็บ:

```bash
npm run dev
```

เปิด URL ที่ Vite แสดง (ปกติ `http://localhost:5173`) การวิเคราะห์คะแนนตามคำสำคัญไม่ต้องมี OpenAI API Key แต่การจัดเก็บ/ดูไฟล์ต้นฉบับและ OCR ต้องเปิด backend ไว้

## ใช้งาน AI จริง (ทางเลือก)
1. คัดลอก `.env.example` เป็นไฟล์ `.env` ที่โฟลเดอร์หลัก
2. ใส่ API key ของคุณใน `OPENAI_API_KEY` และกำหนด `OPENAI_MODEL` หากจำเป็น
3. เปิด terminal หนึ่งหน้าต่างรัน `npm run server`
4. อีกหน้าต่างรัน `npm run dev`
5. เปิดรายละเอียดผู้สมัครแล้วกด **สร้างสรุปด้วย AI**

API Key ใช้ใน Node backend เท่านั้น ห้ามใส่ในตัวแปร `VITE_*` หรือโค้ด frontend หากไม่มี key ระบบจะแจ้งว่าใช้ไม่ได้และยังใช้การวิเคราะห์ตามเกณฑ์แบบ local ได้

## วิธีทดสอบสำหรับมือใหม่
1. เปิดเว็บแล้วตรวจป้าย “ข้อมูลตัวอย่าง” บน Dashboard
2. ไปที่ **ตำแหน่งงาน** ทดลองเพิ่มตำแหน่ง ตรวจให้ weight รวมเป็น 100% แล้วบันทึก
3. ไป **อัปโหลดเรซูเม่** เลือกตำแหน่งงานและเพิ่ม PDF หรือรูปภาพ ระบบจะแสดงสถานะรายไฟล์; PDF สแกน/รูปภาพต้องเปิด backend และติดตั้ง Tesseract พร้อมภาษาไทย/อังกฤษ
4. ไป **ผู้สมัคร** ค้นหา/กรอง/เรียงคะแนน และเลือกผู้สมัครมากกว่าหนึ่งคนเพื่อเปรียบเทียบ
5. คลิกชื่อเพื่อดูหลักฐานคะแนน แก้ข้อมูล เพิ่มบันทึก HR และเปลี่ยนสถานะ; กด **ดูเรซูเมต้นฉบับ** เพื่อเปิดไฟล์จริงหรือดาวน์โหลด
6. กดส่งออก CSV หรือไปที่ **รายงาน** เพื่อส่งออกรายงาน
7. กด **ล้างข้อมูลตัวอย่าง** เพื่อลบเฉพาะข้อมูล demo หรือ **รีเซ็ตการทดลอง** เพื่อล้างข้อมูลทั้งหมดในเครื่องนี้

## สถานะการตรวจสอบ
- ตรวจ TypeScript ด้วย `tsc -p tsconfig.app.json` และตรวจไวยากรณ์ backend ด้วย `node --check server/index.js`
- ต้องทดสอบ `npm run build` และอัปโหลด PDF/รูปภาพจริงบนเครื่อง Windows ที่ติดตั้ง dependencies และ Tesseract ตามที่ใช้งานอยู่
- การเรียก OpenAI จริงต้องตั้งค่า API Key ใน `.env`; ไม่จำเป็นสำหรับ OCR หรือคะแนนจากเกณฑ์

## ข้อจำกัดและความเป็นส่วนตัว
- ระบบใช้ SQLite ของ backend เป็นแหล่งข้อมูลเมื่อเชื่อมต่อได้ และใช้ `localStorage` เป็นข้อมูลสำรองของเบราว์เซอร์; ไฟล์ต้นฉบับจะจัดเก็บใน `data/uploads` และผูกกับรหัสผู้สมัครในตาราง `candidate_files`. ห้ามลบโฟลเดอร์ `data` หากต้องการรักษาฐานข้อมูลและไฟล์ต้นฉบับ
- **ข้อจำกัดด้านความปลอดภัย:** เวอร์ชันนี้ยังไม่มีระบบล็อกอิน/บทบาทผู้ใช้และยังไม่ใช่ระบบหลายผู้ใช้ที่พร้อมเปิดสู่สาธารณะ ควรใช้เฉพาะเครื่องหรือเครือข่ายที่เชื่อถือได้จนกว่าจะเพิ่มการยืนยันตัวตน การกำหนดสิทธิ์ และการตรวจสอบ audit แบบผู้ใช้จริง
- เมื่อกดใช้ AI backend จะส่งข้อความเรซูเม่และเกณฑ์ที่เลือกไปยังผู้ให้บริการโมเดลผ่าน API กรุณาใช้ข้อมูลทดลองหรือผ่านการอนุญาตเท่านั้น
- PDF ภาพสแกนและรูปภาพใช้ Tesseract OCR ในเครื่อง; ผล OCR อาจผิดพลาดและ HR ควรตรวจข้อความกับเอกสารจริง
- คะแนนแสดงการพบคำสำคัญเทียบกับเกณฑ์ของ HR อาจพลาดคำพ้องความหมายและไม่แทนการประเมินของคน HR
- ไม่ใช้ชื่อ/เพศ/อายุหรือข้อมูลอ่อนไหวคำนวณคะแนน และไม่มีการปฏิเสธอัตโนมัติ
